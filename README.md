### 📋 О проекте

Проект направлен на решение задачи автоматизации мониторинга линий электропередачи - трудоёмкого и опасного процесса, традиционно выполняемого персоналом. Наша модель позволяет дистанционно выявлять дефекты и повреждения, обеспечивая переход от реактивного ремонта к проактивному обслуживанию.

### 🔍 Ключевые функциональности
Модель способна:
- Обнаруживать и классифицировать объекты: Детектирование 8 типов критически важных элементов ЛЭП.
- Оценивать техническое состояние: Определение повреждений, таких как трещины, отсутствующие элементы и деформации.
- Интегрироваться в системы мониторинга: Работа в составе автоматизированных систем на базе дронов или стационарных камер.

### 🛠 Установка и использование
**Бекенд:**
```bash
cd backend
python -m venv venv
venv\Scripts\activate.bat
pip install -r requirements.txt
```

**Фронтенд:**
```bash
cd frontend
npm install
```

**Запуск из корневой папки:**
```bash
python start.py
```
После запуска сайта следуйте инструкциям на экране.
